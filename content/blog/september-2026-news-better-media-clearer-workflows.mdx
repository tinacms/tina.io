The herd has been busy again 🦙.

Since August, TinaCMS and TinaCloud team shipped a total of **12 production releases** and **109 changes**. The team shipped 90 features and fixes, plus 23 dependency entries. Here are a few changes worth catching up on.

## 📦 TinaCMS: 3 releases, 18 changes

### 🖼️ More control over media

Image fields can now restrict accepted file types, and the rule also applies to list fields and the media picker. The Media Manager can rename assets in TinaCloud, including branch-aware renames ([#4835](https://github.com/tinacms/tina.io/pull/4835), [#4887](https://github.com/tinacms/tina.io/pull/4887), [#7477](https://github.com/tinacms/tinacms/pull/7477), [#7423](https://github.com/tinacms/tinacms/pull/7423)).

### ⚡ A lighter editor load

Mermaid diagrams now load only when a document uses them. In the kitchen-sink admin build, the entry bundle dropped from 6.34 MB to 5.70 MB, with the diagram library fetched separately when needed ([#7467](https://github.com/tinacms/tinacms/pull/7467)).

### Fewer snags while editing

Optional rich-text fields can now pass `null` or `undefined` straight to TinaMarkdown. Nested panel edits survive navigation, expired sessions return editors to login instead of leaving a misleading save error, and `Shift+Enter` line breaks now survive a save ([#7229](https://github.com/tinacms/tinacms/pull/7229), [#7520](https://github.com/tinacms/tinacms/pull/7520), [#7486](https://github.com/tinacms/tinacms/pull/7486), [#7452](https://github.com/tinacms/tinacms/pull/7452)).

## ☁️ TinaCloud: 8 production releases, 72 feature and fix entries, 19 dependency entries

### 🔐 More useful admin and account tools

AuthKit accounts can enrol in MFA. Staff can now find customer projects and manage project and organisation details, contributor seats, and change history from the admin panel ([#4889](https://github.com/tinacms/tina.io/pull/4889), [#4904](https://github.com/tinacms/tina.io/pull/4904)).

### 🖼️ Media and indexing improvements

Branch-aware media renaming is here, and indexing reports a specific failure instead of the catch-all “Please try again”. TinaCloud also validates schemas before marking indexing successful and can recover failed index migrations ([#4821](https://github.com/tinacms/tina.io/pull/4821), [#4883](https://github.com/tinacms/tina.io/pull/4883), [#4891](https://github.com/tinacms/tina.io/pull/4891)).

### 🧹 A little housekeeping that matters

The team patched an XML parser issue that could break SST deployments, improved account and permission handling, and tidied dependencies across the Cloud services ([#4821](https://github.com/tinacms/tina.io/pull/4821), [#4830](https://github.com/tinacms/tina.io/pull/4830), [#4831](https://github.com/tinacms/tina.io/pull/4831)).
