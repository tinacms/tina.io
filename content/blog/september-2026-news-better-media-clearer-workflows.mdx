The herd has been busy again 🦙. So far in September, TinaCMS core shipped three releases and TinaCloud shipped eight production releases. Stacking up to 90 feature and fix entries, plus 23 dependency entries. Here are a few changes worth catching up on:

## 📦 TinaCMS: 3 releases, 18 changes

### 🖼️ More control over media

Image fields can now restrict accepted file types, and the rule also applies to list fields and the media picker ([#7477](https://github.com/tinacms/tinacms/pull/7477)). The Media Manager can rename assets in TinaCloud, including branch-aware renames ([#7423](https://github.com/tinacms/tinacms/pull/7423)).

### ⚡ A lighter editor load

Mermaid diagrams now load only when a document uses them. In the kitchen-sink admin build, the entry bundle dropped from 6.34 MB to 5.70 MB, with the diagram library fetched separately when needed ([#7467](https://github.com/tinacms/tinacms/pull/7467)).

### Fewer snags while editing

Optional rich-text fields can now pass `null` or `undefined` straight to TinaMarkdown. Nested panel edits survive navigation, expired sessions return editors to login instead of leaving a misleading save error, and `Shift+Enter` line breaks now survive a save ([#7229](https://github.com/tinacms/tinacms/pull/7229), [#7520](https://github.com/tinacms/tinacms/pull/7520), [#7486](https://github.com/tinacms/tinacms/pull/7486), [#7452](https://github.com/tinacms/tinacms/pull/7452)).

## ☁️ TinaCloud: 8 production releases, 72 feature and fix entries, 19 dependency entries

### 🔐 More useful admin and account tools

AuthKit accounts can enrol in MFA ([#4101](https://github.com/tinacms/tinacloud/pull/4101)). Staff can find customer projects and manage project and organisation details, contributor seats, and change history from the admin panel ([#4195](https://github.com/tinacms/tinacloud/pull/4195), [#4197](https://github.com/tinacms/tinacloud/pull/4197), [#4198](https://github.com/tinacms/tinacloud/pull/4198), [#4199](https://github.com/tinacms/tinacloud/pull/4199)).

### 🖼️ Media and indexing improvements

Branch-aware media renaming is here ([#3921](https://github.com/tinacms/tinacloud/pull/3921)), and indexing reports a specific failure instead of the catch-all “Please try again” ([#4069](https://github.com/tinacms/tinacloud/pull/4069)). TinaCloud also validates schemas before marking indexing successful ([#4100](https://github.com/tinacms/tinacloud/pull/4100)) and can recover failed index migrations ([#4120](https://github.com/tinacms/tinacloud/pull/4120)).

### 🧹 A little housekeeping that matters

The team patched an XML parser issue that could break SST deployments ([#4046](https://github.com/tinacms/tinacloud/pull/4046)), tightened organisation-role permissions ([#4066](https://github.com/tinacms/tinacloud/pull/4066)), and fixed a content API compression issue ([#4113](https://github.com/tinacms/tinacloud/pull/4113)).
