## 什么是 TinaCloud Beta 版本？

TinaCloud Beta 版本为早期采用者提供了测试可视化内容编辑和我们基于 Git 的内容 API 的机会！

TinaCloud 将 TinaCMS 的开源内容编辑器与一个 GraphQL API 结合在一起，该 API 与存储在您仓库中的内容（即 Markdown 和即将支持的 JSON）进行通信。

## 我应该从哪里开始？

- 查看更新的 [TinaCloud 文档](/docs/setup-overview/) 并尝试一个入门项目。
- [注册 TinaCloud](https://app.tina.io/register)！
- [在 Discord 上找到我们](https://discord.com/invite/zumN63Ybpf)

## 关于使用 TinaCloud 的 Alpha 版本，我需要了解什么？

由于这是一个 Beta 版本，您应该预期偶尔会遇到错误，或者由于 API 改进而需要更新代码。

这些功能尚未（但即将）包含在 TinaCloud 中，您可能会错过它们：

- 多分支工作流
- 您的内容的 GraphQL API 尚不能使用只读令牌进行查询。这意味着它仅在使用 TinaCMS 编辑内容时使用。

## 使用 TinaCloud 时，我应该考虑哪些技术因素？

如果您的项目包括以下内容，您将在使用 TinaCloud 时取得成功：

- [Next.js](https://nextjs.org/) - 这个出色的 React 框架的灵活性降低了使用 TinaCloud 构建的门槛。
- GitHub - TinaCloud 集成的第一个 Git 提供商。未来可能会提供其他 Git 提供商。
- 静态、基于文件的构建 - TinaCloud 客户端在构建时收集您的文件系统内容。在构建期间从我们的云 API 获取内容的功能即将推出。

[Next.js 入门项目](https://github.com/tinacms/tina-cloud-starter) 可以帮助您快速启动并运行上述考虑事项。试试看，并告诉我们如何让使用 TinaCMS 的开发更容易。

## TinaCloud 的定价是什么？

在我们公开之前，TinaCloud 仍然是免费的。我们仍在制定我们的定价模型，并将为个人使用提供一个永久免费的计划。

如果您的用例符合我们为大型团队提供的付费计划，我们将与您联系。
