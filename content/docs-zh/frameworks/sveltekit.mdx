## 简介

TinaCMS 可以在本地添加到你的 SvelteKit 站点中。本文将引导你完成本地设置，以及在生产站点上进行编辑。

## 快速开始

在站点目录下运行：

```bash
 npx @tinacms/cli@latest init
```

它会询问你几个设置问题。

> 如果你是从 Forestry.io CMS 导入站点，部分模型与配置会被自动导入。

## 更新构建脚本

```json
  "scripts": {
    "dev": "tinacms dev -c \"vite dev\"/",
    "build": "tinacms build && vite build",
    "preview": "tinacms build && vite preview"
  }
```

## 移动静态文件

TinaCMS 默认假定你的静态文件位于 `public` 目录，但 SvelteKit 是从 `static` 目录提供静态文件的。你需要确保 Tina 配置为使用该目录。

确认 `static` 下同时存在这两个目录：

```bash
 # Tina 管理后台
 static/admin/index.html
 
 # Tina 媒体/图片
 static/images
```

## 调整 Tina 配置

更新输出目录，使其指向 SvelteKit 所使用的 `static` 目录：

```js
import { defineConfig } from 'tinacms';
export default defineConfig({
  // ... 其他配置
  clientId: process.env.PUBLIC_TINA_CLIENT_ID,
  token: process.env.TINA_TOKEN,
  build: {
    outputFolder: 'admin',      // 这会生成 static/admin
    publicFolder: 'static'      // SvelteKit 必需
  },
  media: {
    tina: {
      mediaRoot: 'images',      // static/ 内的文件夹
      publicFolder: 'static'    // SvelteKit 必需
    }
  },
  schema: {
    collections: [
      {
        name: 'post',
        label: 'Posts',
        path: 'content/posts', // Markdown 文件所在位置
        fields: [ /* ... */ ]
      }
    ]
  }
});
```

## 建模你的内容

要在 Tina 中编辑站点内容，你可以在 `tina/config.ts` 文件里对内容进行建模。

进一步了解[内容建模](/docs/schema/)

## 启动 TinaCMS

你可以通过以下命令启动 TinaCMS：

```bash
npm run dev
```

TinaCMS 运行后，访问 `http://localhost:5173/admin/index.html`

> 提示：如果运行该命令时遇到错误，请参阅[常见错误](/docs/forestry/common-errors)页面。

此时，你应该已经能看到 Tina 管理后台，可以选择一篇文章、保存修改，并看到更改被写入本地 Markdown 文件。
