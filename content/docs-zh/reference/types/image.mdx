一个专用的文件输入，用于存储上传图片的URL或路径。

它支持[外部媒体库集成](/docs/reference/media/overview#external-media-providers)，也支持[基于仓库的媒体配置](/docs/reference/media/repo-based)。

可以通过拖放操作将图片上传到图片组件，或者使用CMS附带的专用媒体管理器。

> 要修改可以上传到媒体管理器的文件类型，请查找[支持的文件类型列表](/docs/reference/media/repo-based#supported-media-types)和[如何覆盖默认接受的媒体类型](/docs/reference/media/overriding-accepted-media-types)

## 示例

### 简单字段

```ts
{
  type: 'image',
  label: '主图',
  name: 'imgSrc',
}
```

![](/img/docs/reference/SCR-20250313-nzau.png)

### 带有图片路径格式化的字段

如果需要自定义字段中图片的格式，可以使用 `format` 和 `parse` 选项。

```js
{
  type: "image",
  name: "heroImg",
  label: "主图",
  ui: {
    format(value) {
      // 如果值不存在前导斜杠，则添加
      return value.startsWith("/") ? value : `/${value}`;
    },
    parse(value) {
      // 如果存在前导斜杠，则移除
      return value.startsWith("/") ? value.slice(1) : value;
    },
  }
}
```

### 限制文件类型

设置 `accept` 以限制字段为某些文件类型。它接受单个扩展名、类别或它们的数组。

```ts
{
  type: 'image',
  label: '宣传册',
  name: 'brochure',
  accept: 'pdf',
}
```

```ts
{
  type: 'image',
  label: '标志',
  name: 'logo',
  accept: ['png', 'svg'],
}
```

四个类别是扩展名组的简写：

| 类别         | 扩展名                                           |
| ------------ | ------------------------------------------------ |
| `image`      | `jpg`, `jpeg`, `png`, `gif`, `webp`, `svg`, `avif`, `ico` |
| `video`      | `mp4`, `webm`, `mov`                             |
| `audio`      | `mp3`, `wav`, `ogg`                              |
| `document`   | `pdf`, `json`, `csv`, `txt`                      |

当字段声明 `accept` 时：

* 媒体管理器仅列出匹配的文件，其类型过滤器被替换为一个锁定的芯片，标明字段接受的内容。
* 任何其他类型的文件在上传前都会被拒绝，无论是拖放到字段上还是媒体管理器上，因此不会有不需要的文件进入你的库。
* 选择一个不匹配的库中已有文件会引发警报，并保持字段的值不变。
* `jpg` 和 `jpeg` 意味着相同的东西，所以 `accept: 'jpeg'` 仍然接受 `photo.jpg`。
* 字段的 `accept` 仅覆盖全局的 [`media.accept`](/docs/reference/media/overriding-accepted-media-types)。

在添加 `accept` 之前保存的值保持不变；限制适用于编辑者从现在开始选择的内容。它也适用于 `list: true` 的图片字段。

> 缩小库需要一个可以按扩展名过滤的媒体存储。基于仓库的媒体、TinaCloud 媒体和本地开发服务器都可以。不能的存储，如 `staticMedia`，会继续列出所有内容并隐藏过滤控制，但字段仍然会拒绝不在其类型范围内的文件。
