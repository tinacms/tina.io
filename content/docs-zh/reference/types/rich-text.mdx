富文本字段存储**Markdown内容**，具有所见即所得的界面，支持文本格式化、链接、媒体和自定义元素（如果与mdx一起使用）。

## 换行

要在TinaCMS富文本中插入可见的换行（例如，在引用中），请在您想要换行的地方按**Shift + Enter**（软回车）。

保存后，检查Markdown。保留的换行显示为独立的`\`行：

```markdown
> 引用文本…
> \
> 作者姓名
```

> 此行为不是标准Markdown规范的一部分，而是TinaCMS富文本实现的特定功能。

### 列对齐

> 可视化编辑器当前不支持通过工具栏设置列对齐。如果需要在表格列中对齐内容，可以切换到原始Markdown模式并编辑表头分隔行中的对齐语法。

示例——居中第二和第三列：

```
| 对齐方式   |  分隔符  |    示例 |
| :---        |   :---:     |       ---: |
| 左对齐        |   `:---`    |       左对齐 |
| 居中      |   `:---:`   |     居中 |
| 右对齐       |   `---:`    |      右对齐 |
```

要了解更多关于对齐语法的信息，请参考[Markdown扩展语法](https://www.markdownguide.org/extended-syntax/#alignment)

## 高亮

### 自定义高亮颜色

您可以在富文本字段中启用文本高亮，并通过向字段的`overrides`添加`highlightColors`数组来定义可供编辑者使用的高亮颜色。

```ts
export const heroBlockSchema = {
  fields: [
    {
      label: "文本",
      name: "text",
      type: "rich-text",
      overrides: {
        highlightColors: [
          { label: "紫色", value: "rgba(142, 132, 255, 0.55)" },
          { label: "蓝色", value: "rgba(132, 255, 255, 0.55)" }
        ],
      },
    },
  ],
}
```

## 示例

TinaCMS将根据提供的配置生成适当的组件。

### 简单字段

```javascript
{
  label: "正文",
  name: "body",
  isBody: true,
  type: "rich-text",
}
```

### 带工具栏覆盖的简单字段

更改您想要显示的内容及其在编辑器中的显示顺序

```javascript
{
		type: "rich-text",
		name: "body",
		label: "正文",
		isBody: true,
		overrides: {
			toolbar: ["heading", "bold", "italic"],
			showFloatingToolbar: false,
		},
}
```

### 限制可用的标题级别

使用`headingLevels`控制编辑者可以选择的标题。传递`['h1', 'h2', 'h3', 'h4', 'h5', 'h6']`的任何子集，以任何顺序——该值应用于标题下拉菜单、“转换为”菜单、斜杠菜单和Markdown自动格式化快捷方式（例如，输入`## `用于h2）。当省略时，所有六个级别都可用。

```js
{
  type: 'rich-text',
  label: '摘要',
  name: 'excerpt',
  overrides: {
    toolbar: ['heading', 'bold', 'italic', 'link'],
    headingLevels: ['h2'],
  },
}
```

> `headingLevels`在**tinacms@3.8.4**中发布。更新您的包以使用它。

此选项仅限于UI——它限制了编辑者可以插入的内容。已经使用不允许级别的现有内容仍然按原样呈现。传递一个空数组（`headingLevels: []`）将从编辑器中移除所有标题级别。

### 带自定义组件的字段（`mdx`）

自定义组件可以嵌入到富文本块中。

```ts
{
  label: "正文",
  name: "body",
  isBody: true,
  type: "rich-text",
  templates: [
    {
      name: "Cta",
      label: "Cta",
      fields: [{
        name: "heading",
        label: "标题",
        type: "string"
      }
    ]}
  ]
}
```

### 带默认富文本值的集合

要为富文本字段设置默认值，应指定整个AST树，如下例所示。

> 推荐的方法是填写您的数据，然后`console.log`相关字段的CMS API返回值。\
> \
> 然后将其从那里复制到集合的`defaultItem`属性中。

```javascript
{
  label: '博客文章',
  name: 'post',
  path: 'content/posts',
  defaultItem: () => {
    return {
      title: '我的新文章',
      body: {
        type: 'root',
        children: [
          {
            type: 'p',
            children: [
              {
                type: 'text',
                text: '默认文本',
              },
            ],
          },
        ],
      },
    }
  },
  fields: [
    {
      type: 'string',
      label: '标题',
      name: 'title',
    },
    {
      type: 'string',
      label: '文章正文',
      name: 'body',
      isBody: true,
    },
  ],
}
```
