要快速设置一个新的Tina starter，请在命令行中输入：

```bash
npx create-tina-app@latest
```

接下来，您将被提示回答一些快速设置问题：

![](/img/docs/introduction/cli-starter.png)

一旦您的本地starter创建完成，要运行starter，请按照CLI中的说明进行操作：

1\. 使用`cd <your-starter-name>`进入项目目录。

2\. 使用您选择的软件包管理器的开发命令运行项目。请参见下面的pnpm。

```
pnpm run dev
```

## 我应该选择哪个starter？

**Astro是我们的默认starter。** 我们推荐它用于新项目，并且我们首先针对它进行构建和测试。它提供了[无React的可视化编辑](/docs/contextual-editing/astro/)，因此编辑者可以获得实时预览，而访问者则获得纯静态HTML。请参阅[Astro + TinaCMS设置指南](/docs/frameworks/astro/)了解其中的内容。

要跳过提示并直接搭建Astro starter：

```bash
npx create-tina-app@latest --template tina-astro-starter
```

其他starter仍然可用并受到支持。如果您已经决定使用某个框架，例如如果您正在基于[Next.js](/docs/frameworks/next/app-router/)构建项目，可以选择Next.js starter。
