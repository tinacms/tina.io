> “计算机科学中只有两个难题：缓存失效和命名事物。”

这个公理，[归因于Phil Karlton](http://www.tbray.org/ongoing/When/200x/2005/12/23/UPI)，与任何在软件领域工作过的人都有共鸣。您正在阅读的这篇文章在某种程度上是关于后一个问题的。

我们急于在TinaCMS中引入的一个概念是我们称之为**区块字段**的东西。我们在Forestry中首次引入了这个概念，我们认为这是一个强大的想法。区块的挑战在于它是一种抽象的概念，因此被标记为一个同样抽象的名称。

**什么是区块？** 简而言之，区块指的是由*不同对象的数组*组成的数据结构。如果您不太理解，请继续阅读，我会尽力解释为什么我们将区块概念引入TinaCMS以及它与其他类型字段的关系。

## 简单字段和复合字段

我们在TinaCMS中实现的字段类型可以大致分为两类：**简单字段**和**复合字段**。字段是简单还是复合的区分与字段表示的数据类型有关。

**简单字段**是可以表示为单个值的数据字段，如字符串或数字。在计算机科学术语中，这些被称为[标量值](https://softwareengineering.stackexchange.com/questions/238033/what-does-it-mean-when-data-is-scalar)。TinaCMS中的简单字段示例包括文本字段、颜色字段或切换。即使是[markdown WYSIWYG](/docs/editing/markdown)也可以被视为简单字段，尽管其前端行为复杂，因为它导出的值只是一个大块文本。

**复合字段**是不能用单个值表示的字段。复合字段导出的数据是*结构化的*。保存时，复合字段的数据将由非标量数据类型表示，如数组或对象。复合字段是**由其他字段组成的字段**。TinaCMS中的复合字段包括组、组列表和区块。

## 组和组列表

TinaCMS的**组**字段是**简单字段**的集合。组成组字段的字段可以是相同类型，也可以是不同类型。组字段适合表示由较小数据片段组成的单个*实体*。

考虑在JSON中存储名称的两种方式。我们可以将全名存储为一个简单字符串：

```json
{
  "name": "DJ Walker"
}
```

或者，我们可以设计一个简单的数据结构，以更语义化的方式存储名称：

```json
{
  "name": {
    "first": "DJ",
    "last": "Walker"
  }
}
```

在第一种情况下，我们可能会使用一个简单的文本字段，而在第二种情况下使用两个文本字段的**组**。

### 组列表

<Diagram alt="链接圆圈的图示" src="/img/blog/fig-group-grouplist.svg" />

**组列表**类似于**组**字段类型，但增加了一个维度。组字段表示单个实体，而组列表表示*多个实体*。

假设我们不是存储一个名字，而是存储一个名字列表，如下所示：

```json
{
  "subscribers": [
    {
      "first": "DJ",
      "last": "Walker"
    },
    {
      "first": "Nolan",
      "last": "Phillips"
    }
  ]
}
```

我们可以在这里使用**组列表**。组列表中的所有实体具有相同的**形状**；换句话说，数组中的每个对象将具有相同的键。这使得组列表类似于二维数据结构，如电子表格或数据库表：

| **first** | **last** |
| --------- | -------- |
| DJ        | Walker   |
| Nolan     | Phillips |

## 区块：像组列表，但不同

<Diagram alt="不同形状链接在一起的图示" src="/img/blog/fig-blocks.svg" />

像**组列表**一样，**区块**结构表示多个实体。组列表和区块之间的区别在于区块结构支持*具有潜在不同形状*的多个实体。这使得区块结构中实体之间的关系比组列表更松散。

### 区块有什么用？

在实践中，有几个用例特别适合区块。

区块风格数据结构的主要动机是促进页面构建器体验。在我们的[Tina Grande starter](https://github.com/tinacms/tina-starter-grande)中，可以通过向区块字段添加不同的实体来串联页面，每个实体包含配置页面不同部分的字段。

Grande使用区块的另一种方式是在其嵌入式表单构建器中。像页面构建器一样，Grande将表单视为一系列松散相关的复杂组件（在这种情况下是表单字段）。
